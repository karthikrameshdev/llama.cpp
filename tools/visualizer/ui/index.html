HOW TO READ THE OBSERVATORY

            
A window into execution.

            

                The model catalog preloads GGUF weights, structural modules,
                every expert and named operations from a one-token runtime
                inspection. Prompts and replay change highlights in place.
                Original per-step runtime graphs remain preserved in SQLite.
            

            

                Layers groups the catalog by component and
                layer. Operations expands its entries. Runtime
                variants map onto existing modules, keeping camera and model
                geometry fixed. Hover or click for weight pages and hidden
                channels.
            

            

                Full capture observes every scheduled operation
                and samples up to 256 output values. It also records FFN hidden
                channels for the first token of each step, up to 262144 values
                per tensor, and layer output channels. Layer mode observes layer
                boundaries and routing. Routing mode preserves the graph and
                actual expert IDs. Slow replay advances recorded operations at
                the selected rate.
            

            

                Callback wall intervals include synchronization and observation
                overhead. They are not exclusive GPU kernel timings. Fused
                backend kernels may be represented by fewer scheduled graph
                operations. Arbitrary uninstrumented processes cannot be
                attached after context creation.
            

            

                Prompt data and traces stay on your machine. Use the JSON /
                JSONL actions to export a selected prompt. Restarting the
                application keeps its saved history.
